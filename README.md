# Travel Planner: данные

Данные для сервиса планирования поездок по России. Все цены указаны на одного человека в рублях, по ценам осени 2026 года.

## Таблицы в папке `data/`

**cities.csv**: города отправления и места отдыха.
- `name`: название;
- `role`: «отправление» или «отдых»;
- `rest_type`: тип отдыха (море, природа или экскурсии);
- `region`: регион.

**routes.csv**: как добраться из города в место отдыха.
- `origin`, `destination`: откуда и куда;
- `transport`: вид транспорта (машина, автобус, поезд плацкарт, поезд купе, самолёт);
- `distance_km`: расстояние;
- `price_one_way`: цена в одну сторону;
- `hours_one_way`: время в пути;
- `note`: примечание;
- `source`: откуда взята цена;
- `seasonal`: 1, если цена меняется по сезону.

**transport_season.csv**: коэффициенты цены билетов по месяцам.
- `month`: месяц;
- `plackart_coef`, `kupe_coef`, `plane_coef`: коэффициенты для плацкарта, купе и самолёта.

**housing.csv**: жильё.
- `destination`: место;
- `level`: уровень (хостел, отель 3*, отель 4*);
- `name`: объект;
- `price_per_night`: цена за ночь.

**seasonality.csv**: сезонность по месяцам.
- `destination`, `month`: место и месяц;
- `housing_coef`: коэффициент цены жилья;
- `is_season`: 1, если месяц подходит для поездки.

**food.csv**: питание.
- `destination`: место;
- `level`: уровень (эконом, средний, высокий);
- `price_per_day`: расход в день.

**activities.csv**: развлечения.
- `destination`: место;
- `name`: название;
- `price`: цена;
- `hours`: длительность;
- `category`: категория;
- `months`: месяцы, когда доступно.

**real_prices.csv**: реальные цены билетов с сайтов (tutu.ru, aviasales.ru и др.).
- `origin`, `destination`, `transport`: откуда, куда и на чём;
- `month`: месяц;
- `price`: цена;
- `distance_km`: расстояние;
- `hours`: время в пути;
- `source`: сайт;
- `url`: ссылка на страницу.

**settings.json**: общие параметры: цена бензина, расход топлива, формулы цен.

Цена в нужный месяц = базовая цена × коэффициент месяца.

Данные сгенерированы с помощью ИИ.
